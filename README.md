# NetWatch-IDS
# 🛡️ PySentinel-IDS Mini NIDS en Python/Scapy sous Kali Linux. Analyse le trafic en temps réel, détecte le Ping Flood (ICMP) et le Port Scan (TCP), puis génère des rapports d'incidents. Un projet pratique pour maîtriser la détection comportementale et les protocoles réseau. 🚀 #Cybersecurity #Python
